# ABCD-Dasar
Children may learn to identify and read fundamental alphabets in an entertaining and engaging way with this interactive educational application.

# Features
- **Letter Recognition**  
  Learn to recognize the shapes of letters A–Z.

- **Pronunciation Guide**  
  Audio guides for the correct pronunciation of each letter.

- **Attractive Visuals**  
  Colorful, child-friendly images and animations.

- **Interactive**  
  A simple and intuitive interface designed for children.
