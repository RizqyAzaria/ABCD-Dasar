## 📚 ABCD Dasar

ABCD Dasar is an interactive educational application designed specifically for children to help them learn basic alphabet recognition and pronunciation in a fun, engaging, and child-friendly way.

This application focuses on early literacy by combining visuals, audio, and interactivity to make learning letters A–Z easier and more enjoyable.

---

## ✨ Features

- 🔤 **Letter Recognition**  
  Helps children recognize and memorize alphabet letters from A to Z.

- 🔊 **Pronunciation Guide**  
  Provides clear audio pronunciation for each letter to support correct reading.

- 🎨 **Attractive Visuals**  
  Colorful illustrations and animations designed for children.

- 🧩 **Interactive Learning**  
  Simple, intuitive, and child-friendly interface for easy navigation.

## 👾 How to Run the Project

Follow the steps below to run the **ABCD Dasar** project locally:

1. **Install Required Software**
   - Install **Unity Hub**.
   - Install **Unity 6 (6000.0.57f1)** or a higher version.

2. **Clone the Repository**
   ```bash
   git clone https://github.com/RizqyAzaria/ABCD-Dasar.git
   ``` 

3. **Open the Project in Unity Hub**
   - Launch **Unity Hub**.
   - Click **Add** → **Add project from disk**.
   - Select the `abcd-dasar` project folder.

4. **Import Project Assets**
   - Wait for Unity to complete the asset and package import process.

5. **Open the Main Scene**
   - Navigate to: ```Assets/Scenes```.
   - Open the main scene file in Scene folder.

6. **Run the Application**
   - Press the **Play ▶** button in the Unity Editor.

## 📂 Project Structure

The project follows a clean and modular structure to ensure scalability and maintainability:

```
Assets/
├─ Animations/        # UI and character animations.
├─ Images/            # Sprites, icons, and UI assets.
├─ Scenes/            # Game scenes and learning levels.
├─ Scripts/           # C# scripts (game logic & controllers).
├─ Sounds/            # Narration audio and sound effects.
└─ TextMesh Pro/      # Font for the letters.
```
